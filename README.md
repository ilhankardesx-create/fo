# FoldDesk Prototype

Foldable-first launcher experiment for Galaxy Z Fold style devices.

Prototype v0.1 goals:
- Detect HALF_OPENED / horizontal hinge posture with Jetpack WindowManager.
- Keep a permanent bottom control deck.
- Left side: custom keyboard.
- Right side: touchpad.
- Top side: launcher grid with installed apps.
- Attempt adjacent / bounded launch for selected apps.

This branch is intentionally isolated from the repository's existing main branch.
